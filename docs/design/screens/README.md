# Screens of rounds 11 and 12

Copies of the mock-ups the design session drew on the owner's private design
canvas on 24 November 2026: the social screens (round 11, files `R11-…`) and
keeping and finding recipes (round 12, files `R12-…`). [`DESIGN.md`](../../../DESIGN.md),
section 10, says what each shows and what the owner decided on them.

Each file is one phone screen, 390 by 844, in the canvas's format: the
`<x-dc>` and `<helmet>` elements and the `support.js` script belong to the
canvas, which is not in this repo. The screen itself is plain HTML with
inline styles, so a browser should show it without them, though not
exactly as the canvas does; that has not been checked. Links point to `#mock-up`: they go nowhere. The names and
the email address are made up.

They are a reference, not code: nothing imports them, and a real screen is
built in its app from `DESIGN.md` and the tokens.
